Configure o token para começar
1
Abra o Discord no navegador
Acesse discord.com/app e faça login na sua conta
2
Abra o DevTools (F12)
Vá na aba Network e execute qualquer ação no Discord (ex: abrir um servidor)
3
Encontre o token
Clique em qualquer requisição, vá em Request Headers e copie o valor de authorization
4
Cole o token abaixo
O token é uma string longa (ex: MTA4Mj...)
